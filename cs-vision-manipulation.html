Motivation & The AgTech Challenge

The Engineering Problem

While studying Projective Geometry and Planar Homography from the NPTEL Computer Vision course at IIT Kharagpur (taught by Prof. Jayanta Mukhopadhyay), I identified a pivotal challenge in agricultural automation: accurately mapping 2D visual detections from an overhead camera to reliable 3D robot coordinates for physical manipulation.

Full 3D RGB-D point cloud processing is computationally heavy and often impractical on constrained mobile robot processors in field operations. When agricultural targets reside on a planar surface (e.g. grading tables or flat beds), planar homography offers a lightweight, high-speed deterministic alternative.

Core Project Goals

  • Construct an end-to-end vision-guided manipulation pipeline in ROS 2 Jazzy and Gazebo Harmonic.
  • Formulate and calibrate a 3x3 Homography transformation via Direct Linear Transformation (DLT) with < 0.5 cm reprojection error.
  • Integrate HSV-based OpenCV centroid segmentation with MoveIt 2 (pymoveit2) for collision-free trajectory execution on a 6-DOF industrial arm (RobotAnno EA66).

How the Math & Pipeline Work

01

Planar Assumption

Targets lie on a known plane (table or bed). Camera perspective projection simplifies directly to an invertible 3×3 Homography matrix H with 8 degrees of freedom:

x = H · xplane
02

Calibration via DLT

Using ground-truth spatial markers, we formulate the homogeneous linear system and solve via SVD / Direct Linear Transformation:

Ai · h = 0
03

Segmentation & Moments

BGR images are converted to HSV for lighting-robust color isolation. Target centroids are extracted via 2D spatial moments:

cx = m10/m00,   cy = m01/m00
04

Trajectory Execution

Image coordinates (u, v) map to robot base frame coordinates, paired with downward end-effector quaternions, and commanded collision-free:

(u, v) → Base (X, Y, Z, q)

Pipeline Execution Breakdown

CAM
Overhead Detection

Captures /overhead_cam/image_raw, thresholds HSV color masks, and extracts (u, v) pixel centroids.

MOV
MoveIt 2 Planning

Transforms (u, v) via 3x3 matrix H into base_link coordinates and plans collision-free path via pymoveit2.

GZ
Gazebo Control

Why This Matters in Agricultural Automation

Post-Harvest Sorting & Grading

High-speed conveyor inspection and robotic classification without demanding full 3D point cloud computation, maximizing sorting throughput.

Precision Micro-Weeding

Downward-facing planar homography precisely pinpoints weed centroids across varying soil beds for targeted micro-spraying or mechanical removal.

Greenhouse Nursery Handling

Automated seedling tray indexing, picking, and transplanting where planar geometric assumptions consistently hold true with high repeatability.

Roadmap & Next Steps

1

Physical Hardware Validation

Deploy the calibrated pipeline directly onto the physical RobotAnno EA66 manipulator in the laboratory to validate real-world pick-and-place precision.

2

Intrinsic Lens Distortion Calibration

Incorporate complete camera intrinsic matrix calibration (cv2.calibrateCamera) and undistortion before homography calculation to eliminate radial lens distortions.

3

Integration with Mobile Agricultural Base

Mount the manipulation arm onto an autonomous mobile ground vehicle (e.g., Nova / SATCARD Ackermann rover) for integrated in-field autonomous harvesting and weeding.
